# House Price Prediction and Real Estate Analytics Platform
A full-stack machine learning application for predicting residential property prices and analyzing real estate trends.

## Tech Stack
- Python
- NumPy and Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Django
- Django REST Framework
- MySQL
- React.js
- Tailwind CSS


## Project Modules
1. Data Analysis and Visualization
2. Machine Learning and Prediction Engine
3. Django Backend and REST APIs
4. React Frontend
5. Real Estate Analytics Dashboard
